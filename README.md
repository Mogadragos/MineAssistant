# Tuto pour lier une lampe à un levier :
## Matériel :
- Une enclume
- Une torche de redstone
- Un levier
## Processus de synchronisation :
- Poser l'enclume
- Avec l'enclume, renommer la torche de redstone "::entity_id"
  - entity_id = l'id de la lampe dans Home Assistant, par exemple : "::light.salon"
- Une fois la torche renommée, une description devrait être ajoutée, expliquant l'utilisation de l'outil
- Poser le levier (où tu veux)
- Faire un clic droit sur le levier avec l'outil
- Un MP devrait s'afficher
## Processus de désynchronisation :
- Effectuer un clic droit sur le levier avec le même outil
- OU casser le levier
